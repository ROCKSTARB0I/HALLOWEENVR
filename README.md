# HALLOWEENVR

## ▶ [PLAY](https://rockstarb0i.github.io/HALLOWEENVR/)

Haddonfield, Illinois. October 31, 1978. You are Michael Myers.

A WebXR horror game for Meta Quest (open the PLAY link in the Quest browser and press **Enter VR**), with a mouse-and-keyboard mode on desktop.

**Quest:** left stick walks, right stick turns, the right hand holds the knife, left grip grabs, A opens doors, B pauses.
**Desktop:** WASD, mouse look, click to stab, hold right mouse to grab, E for doors and cars, Q to tilt your head, N for free camera.

Everything (rendering, physics, people, faces, blood, sound, music) is generated in code on its own engine; only three.js is vendored.
